# Open Translator — 使用说明

基于 DeepSeek AI 的 Chrome 浏览器实时翻译插件。一键将网页全文翻译为指定语言，译文内嵌显示，支持双语对照与仅显示译文两种模式。
制作初衷：沉浸式翻译的AI翻译要开通会员，于是用Reasonix+Deepseek做了个简化版，可自行绑定Deepseek API Key，密钥仅保存在本地，不会上传到任何第三方。

---

## 安装

1. 下载本仓库代码或 `git clone`
2. 打开 Chrome，地址栏输入 `chrome://extensions` 回车
3. 右上角打开 **开发者模式**
4. 点击 **加载已解压的扩展程序**
5. 选择本仓库根目录（包含 `manifest.json` 的文件夹）

---

## 首次配置

安装后需要配置 DeepSeek API Key 才能使用翻译功能。

### 获取 API Key

1. 访问 [platform.deepseek.com](https://platform.deepseek.com)
2. 注册/登录账号
3. 进入 **API Keys** 页面，点击 **创建 API Key**
4. 复制生成的 `sk-...` 密钥

> **密钥仅保存在本地浏览器中，不会上传到任何第三方。**

### 填写配置

1. 右键 Chrome 工具栏上的 Open Translator 图标 → **选项**（或点击插件弹窗右下角的 ⚙ 设置）
2. 在 **API Key** 输入框中粘贴密钥
3. 选择模型推理模式：
   - **Flash** (`deepseek-chat`) — 速度快，成本低，日常翻译推荐
   - **Pro** (`deepseek-reasoner`) — 推理更强，翻译质量更高
4. （可选）自定义翻译 Prompt，支持 `${sourceLang}` `${targetLang}` 占位符
5. 点击 **保存设置**

### 译文样式（可选）

在设置页的「译文样式」区域：

- 打开 **启用自定义文字颜色** → 选择颜色 → 译文使用指定颜色
- 打开 **启用自定义背景颜色** → 选择颜色 → 译文使用指定底色
- 关闭开关 → 译文继承原文样式

## 使用方式

### 基本流程

1. 打开任意网页
2. 点击 Chrome 工具栏的 Open Translator 图标
3. 在弹窗中设置：
   - **源语言**（左）— 可选「自动检测」
   - **目标语言**（右）— 翻译结果的语言
4. 点击 **翻译 (Alt+T)** 按钮
5. 页面显示翻译结果，每条原文后有 loading 动画，完成后替换为译文

### 快捷键

| 快捷键 | 功能 |
| --- | --- |
| `Alt+T` | 使用已保存的设置翻译当前页面 |

### 显示模式切换

弹窗左侧按钮可切换两种显示模式：

| 模式 | 效果 |
| --- | --- |
| **双语对照** | 原文和译文同时显示，译文紧接原文后方 |
| **仅显示译文** | 隐藏原文，只显示翻译结果 |

- 翻译前切换：点击翻译后按所选模式展示
- 翻译后切换：已翻译内容立即变换显示模式，无需重新翻译

### 取消翻译

翻译过程中再次点击插件图标，按钮变为红色 **取消翻译 (Alt+T)**，点击后页面恢复原文状态。

## 翻译范围

以下内容**不会被翻译**：

- 代码块（`<code>`、`<pre>`）
- 输入框和文本框（`<input>`、`<textarea>`）
- 带有 `translate="no"` 属性的元素
- 图片、视频、SVG、画布等非文本内容

---

## 翻译状态说明

| 场景 | 翻译是否保留 |
| --- | --- |
| 在当前页面点击翻译 | ✓ 翻译生效 |
| 切换到其他 tab 再切回来 | ✓ 翻译保留（DOM 未销毁） |
| 同一 tab 内点击链接跳转 | ✗ 翻译消失（页面重载），需重新点击翻译 |
| 刷新页面 | ✗ 翻译消失，需重新点击翻译 |

## 隐私与安全

- **API Key** 通过 Chrome `storage.sync` 保存在本地浏览器中，仅用于调用 DeepSeek API，不会上传到任何第三方服务器
- 翻译请求经过插件内置的 Background Service Worker 代理，网页本身无法直接访问 API
- 插件**不收集**用户的网页内容、翻译记录或任何浏览数据
- 插件仅申请了 `storage` 和 `activeTab` 两项最小权限

## 常见问题

**Q: 点击翻译后没有反应？**

A: 请检查设置页中是否已填写 API Key，以及 Key 是否有效（未过期、余额充足）。

**Q: 翻译结果显示「API Key 无效」？**

A: 请确认 API Key 完整粘贴（以 `sk-` 开头），且没有多余空格。

**Q: 翻译速度慢？**

A: 全文翻译的耗时取决于页面文本量和 DeepSeek API 响应速度。可在设置页切换为 **Flash** 模式提高速度。

**Q: 某些文字没有被翻译？**

A: 代码块、输入框、以及标注了 `translate="no"` 的元素会被自动跳过。这是设计行为，避免破坏页面功能。
